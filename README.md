# PageLab

> Local-first HTML workbench for QA, product, and engineering teams.

PageLab 是一个零依赖的本地 HTML 页面工作台。把 HTML 文件拖进浏览器，就能在不上传文件的前提下修改文案、按钮名和样式，检查元素、切换断点、记录验收批注，并导出一份新的 HTML。

它服务于报告验收、原型评审、离线演示页和临时交付物的“最后一公里”；不是 IDE、低代码平台或生产页面的替代品。

## 功能

- 导入或拖入 `.html` / `.htm` 文件，也可从内置验收模板开始
- 原位编辑正文、标题、说明和按钮名；编辑按钮时会阻止其原始点击动作
- 选择区块后复制、排序、删除，并调整文字/背景/边框颜色、字号、圆角、内外边距和属性
- 文本选区支持粗体、斜体、下划线、删除线与颜色调整
- 元素检查器显示标签、CSS 路径、常用样式和非样式属性
- 自适应、1280px、768px、390px 断点预览及画布缩放
- 查找替换、验收批注及批注 JSON 导出
- 源码模式、撤销/重做、回到源版本、本地草稿恢复
- HTML 导出；便携副本会尽力将可读取的图片内嵌为 Data URL

## 快速开始

克隆仓库后，直接打开 `index.html` 即可。也可以启动一个本地静态服务器：

```bash
python3 -m http.server 4173
```

打开 <http://localhost:4173>，然后选择或拖入一个 HTML 文件。

## 使用流程

1. **导入页面**：点击“打开 HTML”，或将文件拖进画布。
2. **改内容**：点击文字或按钮名直接编辑；点击区块后在右侧检查器调整属性和样式。
3. **做验收**：切换桌面、平板、手机宽度，选中元素后记录 P1/P2/P3 批注。
4. **检查与导出**：需要时切到源码模式，确认后导出 HTML 或批注 JSON。

## 安全与边界

- 默认使用静态安全预览，导入文件中的 JavaScript 不会执行。
- 只有需要验证动态行为时才开启“运行脚本”，且仅应打开可信文件。
- 草稿仅保存在当前浏览器的 `localStorage`，不会上传到服务器。
- 跨域图片可能无法内嵌；导出时会保留其原始地址。
- PageLab 编辑的是导入文件副本。正式项目仍应通过源码、Git 和发布流程管理。
